# Serit

Ekranın üstünde, kapanmayan durum bildirimi: çevrimdışı kilidi ve gönderilemeyen yazma.

- Çevrimdışı şeridi (`erp-serit--cevrimdisi`) görünürken bütün yazma düğmeleri pasiftir; `title`'ları "İnternet yok" der.
- Bekleyen yazma şeridi sayıyı ve "Yeniden dene"yi taşır; sessiz kalmaz.
- Şerit metni durumu ve ne olacağını söyler; kullanıcıyı suçlamaz.
