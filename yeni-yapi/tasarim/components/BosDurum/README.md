# BosDurum

Boş liste ya da sonuçsuz arama; "Kayıt yok" demek yerine neyin görüneceğini ve ilk kaydın nasıl ekleneceğini söyler.

- Sağlanan: başlık, bir cümle açıklama, varsa ilk kaydı açan düğme.
- Aramadan dönen boş sonuçta düğme "Süzgeci temizle" olur.
- İkon soluk `erp-text-3`; başlık `erp-text`.
