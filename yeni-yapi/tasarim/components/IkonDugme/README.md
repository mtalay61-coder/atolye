# IkonDugme

Araç çubuğunun ve kart başlığının yazısız düğmesi: 30×30 (dokunmada 44×44), 16px ikon.

- Sağlanan: ikon adı (`assets/Ikonlar`), ad (`aria-label`), `title` = "Ad · Kısayol" ya da pasiflik nedeni.
- `erp-ib--primary` yalnız Yeni ve Kaydet; `erp-ib--danger` yalnız Sil (durağanken nötr, üzerine gelince kırmızı).
- Pencere başlığında (koyu zemin) birincil düğme dolgu yerine `erp-shell-2` zemin alır; iki kırmızı çakışmaz.
- Yazı gerektiren yerde `Dugme` kullanılır, ikon düğmenin yanına yazı eklenmez.
