# Rozet

Bir kaydın durumu; her zaman renk, ikon ve kelime birlikte (`Atolye.rozet(durum, metin)`). Altında süzgeç çipi (`erp-cip`).

- Durumlar sabit: `ok` tamam/onaylı/bitti, `wait` bekliyor/kısmi/yolda, `info` bilgi/taslak/üretimde, `idle` pasif/kapalı, `void` iptal/hata.
- Durum adı bir iki kelime; cümle yazılmaz.
- `erp-wait` küçük yazıda 4,5:1'i tutmaz (3,93:1): yalnız rozette, kalın yazı ve ikonla kullanılır.
- Süzgeç çipi seçiliyken koyu dolgulu, sayıyı taşır: "Açık 24".
