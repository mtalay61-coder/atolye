# Matris

Tek değişken boyutu beden olan her liste için zorunlu görünüm: satırda malzeme (ve renk), sütunda beden, hücrede tek sayı.

- Sağlanan: satırlar (malzeme, renk), beden listesi (ölçü setinin sırasıyla), hücre değerleri; girişte düzenlenebilir hücreler.
- Boş hücre `·` ile soluk yazılır, 0 yazılmaz. Eksi hücre `erp-eksi`.
- Satır sonunda toplam sütunu; gerekirse en altta beden toplamları.
- Sipariş girişi, iş verme, teslim alma, sevk, stok durumu ve hammadde ihtiyacı bu bileşenle çizilir.
- İstisna gerekçesiyle yazılır ("matris-muaf: …").
