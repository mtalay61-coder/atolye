# Ikonlar

Kullanıcının ERP standardındaki 21 çizgi ikon (`erp-icons.svg`), birer dosya olarak. 24×24 görünüm kutusu, 2px çizgi, yuvarlak uç ve köşe.

- Dosyalar önizleme için `erp-text` (#24201b) mürekkebiyle çizili; arayüzde `window.Atolye.ikon(ad)` satır içi SVG verir ve `currentColor` ile boyanır.
- Aksiyonlar: i-plus Yeni, i-save Kaydet, i-edit Düzenle, i-copy Kopyala, i-trash Sil, i-search Ara, i-filter Filtre, i-refresh Yenile, i-print Yazdır, i-export Excel, i-collapse Küçült, i-expand Büyüt, i-close Kapat, i-undo Geri al, i-back Geri.
- Durumlar: i-check tamam, i-clock bekliyor, i-info bilgi, i-ban pasif, i-draft taslak, i-alert hata/iptal.
